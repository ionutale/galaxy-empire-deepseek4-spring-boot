Phase 7a — Frontend Architecture

Persistent Resource Header Bar

A new ResourceBarComponent displayed at the top of every page:

App Navigation
Galactic Empire Planet: Planet-1 | ● Metal: 12,450 ● Crystal: 8,320 ● Gas: 5,180 ⚡ Energy: +42 / 50,000

Implementation Details

  • New component: ResourceBarComponent — standalone, injected into AppComponent above router-outlet
  • Polls GET /planets/{activePlanetId}/resources every 10 seconds
  • Red background bar for resources near cap (>90%) or energy deficit
  • Shows: current amount, storage cap, per-hour production rate (tooltip)
  • Planet selector dropdown lets user switch active planet
  • formatNum() for display (K/M suffixes)

Active Planet State

  • AppComponent holds activePlanetId state
  • Navigating to a planet (overview, resources, etc.) sets it
  • Stored in a simple shared service or BehaviorSubject
  • Resource bar reads from this

Changes to Existing Components

  • OverviewComponent: Remove inline resource display (now in header bar)
  • ResourcesComponent: Keep building grid, remove header resource bar
  • AppComponent: Add <app-resource-bar> before <router-outlet>
