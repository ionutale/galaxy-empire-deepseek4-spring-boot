Phase 7a — Backend Architecture

EconomyService (new)

Central resource authority — all resource operations go through here:

  • checkAndDeduct(planetId, metal, crystal, gas) — validate + deduct atomically
  • refund(planetId, metal, crystal, gas) — refund on queue cancellation
  • addResources(planetId, metal, crystal, gas) — add loot/transport/trade
  • getCurrentResources(planetId) — returns metal/crystal/gas/energy + caps + rates
  • getStorageCaps(planet) — computes storage capacity from building levels

GameLoop Integration

  • Every 10 seconds: economyService.tickResources()
  • Iterates all planets, for each: compute elapsed time since lastUpdate
  • Calculate production: metalRate * hours + crystalRate * hours + gasRate * hours
  • Deduct fusion reactor gas consumption from gas production
  • Apply energy deficit halving
  • Cap all resources to storage capacity
  • Update planet.lastUpdated and resource fields

Fusion Reactor

  • New method in GameBalancer: getFusionEnergy(level) = 30 * level * 1.05^level
  • New method: getFusionGasCost(level) = 10 * level * 1.1^level
  • Energy tech level (from PlayerTechnology) boosts production: 1.05 + 0.01 * energyTechLevel
  • In tickResources(): if gas > gasConsumption, subtract gasConsumption and add fusionEnergy
  • If gas < gasConsumption, reactor produces nothing

Energy Deficit

  • In PlanetService.recalculate(): compute total energy (solar + fusion) — total consumption (mines)
  • If netEnergy < 0: mine production halved (already in GameBalancer formulas)
  • Ensured in tickResources(): pass netEnergy to production calculation

Storage Caps

  • GameBalancer.getStorageCapacity(metalStorageLevel), same for crystal/gas
  • In tickResources(): after adding production, min(resource, storageCap)
  • In checkAndDeduct(): validate resource availability (not cap)

API Endpoints (new on PlanetController)

  • GET /planets/{id}/resources — returns metal, crystal, gas, energy, storage caps, production rates
  • DTO: PlanetResourcesDto with rates, caps, current amounts

Migration V9

  • No new tables needed — everything uses existing Planet fields
  • Add gas_consumption tracking? No — computed dynamically from fusion level
