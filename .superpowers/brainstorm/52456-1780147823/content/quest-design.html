Phase 7b-b: Quests & Achievements

Database Tables

quest_definition — data-driven quest definitions:

id, quest_type (ACHIEVEMENT|DAILY), category (BUILDING|RESEARCH|COMBAT|RESOURCE|GENERAL),
requirement_type (BUILD_X|RESEARCH_X|PRODUCE_X|WIN_BATTLES|...),
requirement_value (target count), reward_type (DARK_MATTER|METAL|CRYSTAL|GAS),
reward_amount, title, description, icon, daily (boolean), sort_order

quest_progress — per-player tracking:

id, player_id, quest_definition_id, progress (current count), 
completed (boolean), completed_at, claimed (boolean), last_reset_date

Event-Driven Progress

QuestEvent record carrying action_type + value. Emitted by services:

  • BuildingService → BUILDING_UPGRADED(type, newLevel)
  • ShipyardService → SHIPS_BUILT(type, quantity)
  • ResearchService → RESEARCH_COMPLETED(technology, level)
  • FleetService / CombatService → BATTLE_WON(shipsDestroyed)
  • EconomyService → RESOURCES_COLLECTED(amount, type)

API Endpoints

  • GET /quests — returns available quests (achievements + today's daily quests)
  • POST /quests/{progressId}/claim — claim reward if completed
  • Quest data includes: title, progress, target, reward, completed, claimed

Frontend

  • Quest button in nav bar — opens quest panel overlay/sidebar
  • Panel shows achievements (one-time) and dailies (recurring)
  • Each quest: progress bar + reward + "Claim" button when complete
  • Badge on nav showing number of claimable quests

Migration V10

Two new tables + seed data for initial quests:

  • ~20 achievements (reach building Lv5/10/15, research techs, build fleets, win battles)
  • ~5 daily quests (produce resources, upgrade buildings, research, battles, login)
