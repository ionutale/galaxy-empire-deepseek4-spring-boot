Phase 7b — Dark Matter: Approaches

Full original scope: achievements + daily quests + purchases + speed-ups + commanders + resource packs

A

Big Bang — Everything in One Phase

Achievements, daily quests, purchases, speed-ups, commanders, resource packs, store UI, quest panel — one design, one plan, one implementation.

Pros

  • Coherent end-to-end
  • Single migration

Cons

  • Very large scope (quest system alone is complex)
  • Commanders need their own data model
  • Long implementation — risk of drag
B

Core DM → Commands & Quests → Store

Phase 7b-a: Dark matter display + earn via purchase endpoint + spend on speed-ups (reuse existing speed-up patterns)
Phase 7b-b: Achievements + daily quests system
Phase 7b-c: Commanders + resource packs + store

Pros

  • Core dark matter (display + spend) ships fast
  • Quests get independent design as a game system
  • Commanders are a big feature — deserve own phase

Cons

  • Three design cycles
  • Speed-up scope might overlap with quest rewards
C

Quest System First — Everything Else Follows

Phase 7b-a: Achievements + daily quests (the earning engine)
Phase 7b-b: Speed-ups + purchases + store (the spending engine)
Phase 7b-c: Commanders + resource packs

Pros

  • Earning established first, spending feels connected
  • Quests are the most unique game system

Cons

  • No way to spend DM until Phase 7b-b
  • Quest rewards need somewhere to go

I recommend B — core DM (display + speed-ups) ships in days, quests get their own thoughtful design, commanders are deferred to avoid scope bloat.
